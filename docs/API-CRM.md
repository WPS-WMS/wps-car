# API — CRM comercial

Gestão de leads, funil de vendas, histórico de contato, follow-up automático e lembretes para vendedores.

Permissões: `crm:read`, `crm:create`, `crm:update`

## Endpoints

| Método | Rota | Permissão | Descrição |
|--------|------|-----------|-----------|
| GET | `/crm/funnel` | `crm:read` | Contagens por status (leads + oportunidades) |
| GET | `/crm/leads` | `crm:read` | Lista paginada de leads |
| POST | `/crm/leads` | `crm:create` | Cadastra lead |
| GET | `/crm/leads/:id` | `crm:read` | Detalhe com contatos e interesses |
| PATCH | `/crm/leads/:id` | `crm:update` | Atualiza lead |
| POST | `/crm/leads/:id/contacts` | `crm:create` | Registra contato no histórico |
| POST | `/crm/leads/:id/interests` | `crm:create` | Registra interesse por veículo |
| GET | `/crm/opportunities` | `crm:read` | Lista oportunidades |
| POST | `/crm/opportunities` | `crm:create` | Cria oportunidade |
| PATCH | `/crm/opportunities/:id` | `crm:update` | Atualiza oportunidade |
| GET | `/crm/reminders` | `crm:read` | Lembretes do vendedor |
| PATCH | `/crm/reminders/:id/complete` | `crm:update` | Conclui lembrete |

## Escopo por perfil

- **SELLER** — vê e edita apenas leads/oportunidades/lembretes atribuídos a si
- **MANAGER / ADMIN** — visão completa da revenda; pode atribuir vendedor

## Cadastro de lead

```json
POST /crm/leads
{
  "name": "João Silva",
  "phone": "11999998888",
  "email": "joao@email.com",
  "source": "WHATSAPP",
  "sellerId": "uuid-do-vendedor",
  "expectedAmount": 85000,
  "notes": "Interessado em SUV",
  "nextFollowUpAt": "2026-06-10T09:00:00.000Z"
}
```

**Origem (`source`):** `WHATSAPP`, `PHONE`, `STORE`, `WEBSITE`, `REFERRAL`, `OTHER`

**Status (`status`):** `NEW`, `CONTACTED`, `QUALIFIED`, `NEGOTIATION`, `WON`, `LOST`

## Histórico de contato

```json
POST /crm/leads/:id/contacts
{
  "channel": "WHATSAPP",
  "summary": "Cliente pediu fotos do veículo",
  "contactedAt": "2026-06-04T14:30:00.000Z"
}
```

**Canal (`channel`):** `PHONE`, `WHATSAPP`, `EMAIL`, `VISIT`, `OTHER`

Contatos via WhatsApp incluem `whatsappLink` (link `wa.me`) na resposta quando o lead possui telefone.

## Interesse por veículo

```json
POST /crm/leads/:id/interests
{
  "vehicleId": "uuid-do-veiculo",
  "notes": "Prefere cor prata"
}
```

## Follow-up automático

Ao definir `nextFollowUpAt` em lead ou oportunidade, o sistema cria/atualiza um `SellerReminder` automático para o vendedor responsável.

## Funil

`GET /crm/funnel` retorna:

```json
{
  "leads": { "NEW": 5, "CONTACTED": 3 },
  "opportunities": { "OPEN": 2, "IN_PROGRESS": 1 }
}
```

## Lembretes

`GET /crm/reminders?status=PENDING&page=1&limit=20`

Lembretes podem ser gerados automaticamente (`autoGenerated: true`) ou manuais.

## Integração WhatsApp

Não há API oficial do WhatsApp — o sistema gera links `https://wa.me/55...` para abrir conversa no app/web.
